## 説明のポイント

- **自分のフォルダだけを触る** ので、同時に作業してもぶつからない (共通ファイルは不要)
- `VITE_` で始まる環境変数は **誰でも見られる**。秘密は入れない
- 環境変数を変えたら **再デプロイ**
- 個人で CLI 公開した Vercel は、main がマージされても自動更新されない (統合版とは別物)

## PR レビューのチェックリスト

- [ ] **表示**: `/#/members/<slug>` とカテゴリ一覧・ホームの新着に出る
- [ ] **操作**: ボタンや入力が実際に動く。エラーが出ない
- [ ] **ビルド**: CI が緑
- [ ] **影響範囲**: 変更が `src/contributions/<slug>/` の中だけ (Files changed タブで確認)
- [ ] **個人情報**: 個人情報・秘密情報・本人の同意のない写真が無い

## よくある質問

- **Q. 自分の Vercel に、ほかの人のページも出てほしい**
  A. main を pull してから `npx vercel --prod` で再デプロイすると反映されます。
- **Q. slug を間違えた**
  A. フォルダ名と `meta.slug` を両方直せば OK。ホームの警告に直し方が出ます。
- **Q. 他の人とコンフリクトした**
  A. 自分のフォルダ以外を触っていないか確認。`package-lock.json` などを変更してしまった場合は、そのファイルの変更を取り消します。
